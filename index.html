    实用贴士

    • 时区10 月 4 日凌晨 2:00 起，新州与维州进入夏令时，时钟直接跳到 3:00，两州由 UTC+10 变为 UTC+11。手机会自动切换，但当晚少睡 1 小时，10/4 这天别排太满。所有倒计时按绝对时刻计算，不受切换影响。
    • 落地通关入境卡（Incoming Passenger Card）在航班上就填好，「是否携带药品 / 食品 / 动植物制品」一栏带了药品必须勾「是」。下机后先过入境检查（中国大陆护照走人工柜台），再取行李，最后过海关 / 生物安全：带了药品就走红色申报通道（Goods to Declare），把药品与处方一起主动递上，通常问两句即放行。规则要点：只带个人自用、3 个月以内用量，保留原包装与处方（最好有英文说明）；含可待因的止咳水、安眠药、强效止痛药必须带处方或医生信；中成药含濒危动植物成分的也要申报；现金超 A$10,000 必须申报。食品、茶叶、蜂蜜、木制品、种子同样要报——未申报被查出来罚款很重，还可能影响签证。
    • 机场打车我们在悉尼落地后直接打车去早餐。T1 到达大厅出来跟绿色「Taxi」牌到地面层出租车站；5 人 + 大件行李要叫 maxi 出租车（7 座，车顶 MAXI 标识），或 Uber XL / DiDi 7 座（网约车走指定上车区，T1 是 Rank C，Uber 要出示 PIN，步行约 5 分钟）。机场 → CBD 有固定价：标准车 A$60、maxi A$80，已含过路费和机场费——但固定价只适用于「从机场排队上车、直达成 CBD 指定区域」，我们的终点在 Surry Hills，不在固定价区内，按表计费约 A$40–55，Uber / DiDi 含机场接客费约 A$55–75，早高峰可能上浮。上车前跟司机确认目的地和大致费用，下车拿收据。不推荐改坐火车：机场两站由私人运营，要在车费外另收机场站附加费约 A$18.61/人，5 人约 A$115，反而比 maxi 出租车贵。
    • 交通卡悉尼用 Opal 卡（火车 / 公交 / 渡轮通用，便利店可购；也可直接拍支持闪付的银行卡），墨尔本用 Myki 卡（电车 / 火车 / 公交）。两城刷卡上下车都要刷，逃票罚款很重。
    • 打车澳洲用 Uber 或 DiDi，进市区也可打 13cabs。墨尔本市区有免费电车区（Free Tram Zone），弗林德斯街、女王市场一带都在圈内。
    • 自驾·证件中国驾照在澳洲不能单独使用，必须配 NAATI 认证的英文翻译件（或国际驾照 IDP）。取车时带三样：驾照原件 + 翻译件 + 主驾名下的信用卡（用于押金预授权）。澳洲靠左行驶、方向盘在右，转向灯拨杆和雨刷位置与国内相反。
    • 自驾·交规环岛一律让右；限速市区 50、学校区上下学时段 40、高速 100–110，超速罚得极重；红灯不能左转（有左转箭头才行）；车上所有人必须系安全带；开车碰手机（包括等红灯时）属严重违章，罚款上千澳元。
    • 自驾·加油无铅汽油认 Unleaded 91 / 95 / 98，柴油是 Diesel，别加错。基本都是自助加油，加完到店里报油枪号付款。悉尼到杰维斯湾沿线镇上加油站不缺，但价差大，凯马一带相对便宜。
    • 自驾·停车路边标识要看仔细：红底 "No Stopping" 一秒都不能停，"No Parking" 可短暂上下客人不离车。付费车位多用咪表或 App，悉尼市区停车贵，优先停住处或正规停车场。
    • 自驾·收费路悉尼 M2 / M5 / M7 等为电子收费，没有人工收费亭。租车公司会自动代扣并加收一笔手续费。去杰维斯湾走王子公路不经过收费路段，不用担心。
    • 退税离境退税 TRS：同一商家累计满 A$300、离境前 60 天内购买、随身携带商品与小票。墨尔本机场 T2 出发层有 TRS 柜台，10/7 是早班机，退税排队要留足时间。
    • 大洋路沿线加油站稀少且偏贵，离开墨尔本前加满油；Wongarra 一带手机信号弱，出发前把导航和住宿联系方式离线存好。
    • 看企鹅菲利普岛企鹅归巢是园区规定最严的一场：全程禁拍照、禁录像（灯光会伤企鹅眼睛），禁闪光灯、禁投喂、禁大声喧哗；10 月海边夜里气温低，厚外套必备，孩子熬不到可以提前撤到后排。
    • 出海观鲸杰维斯湾船上风大浪颠，提前半小时吃晕船药，外套要防风；鲸鱼多在船侧几十米外出现，别为了拍照挤到船沿，带长焦比带广角好使。10/2 是 10:00 出海、12:00 靠岸，下船后要连开 200 公里回悉尼赶飞机——晕船药选不致困的，或吃完让不晕的家人开车。
    • 天气墨尔本一天四季，10 月初白天 15–20℃、早晚偏凉且多风，薄外套 + 防风衣常备；日照强，防晒也别省。海边和十二门徒岩风大，比市区冷一档。
    • 假期10/3–10/5 是长周末（10/5 为新州劳动节），加上学校假期，热门景点、餐厅、包车都建议提前订；十二门徒岩上午 11 点前相对清静，你们正好错峰。
    • 紧急报警 / 救护 / 消防统一拨 000。
    • 电源澳洲插座为 I 型三脚扁插（国内两脚可用，三脚需转换头），电压 220–240V，国内电器可直接使用。
    • 饮水两地自来水可直接饮用；超市买瓶装水更便宜，超市在水产区买海鲜还能现加工。
    • 小费澳洲不强制小费，餐厅账单已含服务费，满意可留 5–10%。
